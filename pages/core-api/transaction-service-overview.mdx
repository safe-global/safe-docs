# Safe Transaction Service API

The Safe Transaction Service offers a REST API to track transactions sent via the Safe Smart Account. It indexes executed transactions, on-chain confirmations, configuration changes, and token transfers, and serves this on-chain data for each supported chain.

The [Safe Queue Service](./safe-queue-service-overview.mdx) handles transaction proposals, off-chain signatures, messages, and delegates, with a single service for all supported chains. To move an integration from the Safe Transaction Service, see the [migration guide](./safe-queue-service-migration.mdx).

Additionally, the Safe\{Core\} SDK provides the [API Kit](../sdk/api-kit.mdx), a TypeScript client for the Safe Transaction Service API.
