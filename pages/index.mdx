Safe is an open-source and modular smart account stack for the secure management of digital assets. These docs cover the Safe\{Core\} tooling and infrastructure for integrating Safe Smart Accounts into your application.

## For AI agents and tools

Machine-readable entry points to these docs and the API:

- [OpenAPI spec](https://api.safe.global/tx-service/eth/schema/): Public OpenAPI 3.1 description of the Safe Transaction Service API for Ethereum. Every supported chain serves its own at `https://api.safe.global/tx-service/{chain}/schema/`.
- [`llms.txt`](https://docs.safe.global/llms.txt): Index of these docs for language models.
- [`llms-full.txt`](https://docs.safe.global/llms-full.txt): The documentation corpus in one file.
